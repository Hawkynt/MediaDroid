vcomp140.dll — the OpenMP runtime of Microsoft Visual C++

The Windows packages (the MSI and the portable zip) carry vcomp140.dll beside MediaDroyd's native library
(mediadroyd.dll), which needs it: ncnn, the neural networks' engine, is built with Visual C++'s OpenMP. It is the file
from the redistributable folder of the Visual Studio that built the package, VC\Redist\MSVC\<version>\x64\
Microsoft.VC14x.OpenMP, unmodified (the published packages: Visual Studio 2026 on GitHub's Windows runners).
